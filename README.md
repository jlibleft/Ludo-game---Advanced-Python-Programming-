# Ludo game - Advanced Python Programming

This repository contains the implementation of digital version the Ludo board game, created for the Advanced Python Programming course. 

## Project Overview

The project implements the core rules of Ludo and handles game state management. By containerizing the application with Docker, the python backend can be hosted easily and accessed across different operating systems.

### Key Features
* Full Ludo rule implementation (starting rules, movement, captures, safe spots, and winning conditions).
* Dockerized setup for easy execution and multi-device connectivity.

## Tech Stack

* Python 3
* Docker & Docker Compose
